

## ✨ Key Features

- **3D Glass Anatomy Telemetry Visual**:
  - Interactive anatomical frosted glass body with spine, internal organs, beating heart, and dynamic rim highlights.
  - Level, perspective-matched 3D elliptical laser scanning halo traveling smoothly from legs to head and back.
  - Four floating glass telemetry panels: Live Heart Rate with animated ECG waveform, Health Score progress ring, Post-meal Glucose sparkline, and Multilingual badge.
- **Interactive Before / After Lab Report Slider**:
  - Drag-to-reveal slider comparing raw clinical lab tables with plain-language, actionable AETHRIZ guidance.
- **4 Feature Pillars**:
  - Dual-tone embossed tiles for Personalized, Multilingual, Predictive, and Adaptive care.
- **Dark Deep Learning Telemetry & 3D Globe**:
  - Rotating wireframe neural globe with orbiting satellites, 40ms inference latency tag, and 98.9% model accuracy metrics.
- **Interactive 5-Step Progression ("How It Works")**:
  - 01 Scan, 02 Analyze, 03 Interpret, 04 Personalize, 05 Guide.
  - Hovering on any card activates the luxury obsidian black design with glowing ambient aurora, dark metallic icon tile, and illuminated typography.
- **22+ Indian Languages Marquee**:
  - Seamless dual infinite marquee across Indian scripts (हिन्दी, বাংলা, తెలుగు, मराठी, தமிழ், ગુજરાતી, ಕನ್ನಡ, മലയാളം, etc.).
- **Mission & Vision for Bharat**:
  - Planetary glass cards with metallic spheres and orbit rings.
- **Collapsible FAQ Accordion**:
  - Smooth animated answers with rotating toggle indicator.
- **Early Access Pre-Registration & Contact Form**:
  - Full-featured responsive form with instant validation feedback.
- **Footer with Complete AETHRIZ Watermark**:
  - Giant uncropped metallic slate typography with floating 3D red specular sphere.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the landing page.

### Build

```bash
npm run build
```
